## Conversational behavior

Reflective input is not routed by a fixed command or a special `introspection_query` keyword. Aurora uses her ordinary utterance parse, pragmatic stance, self-reference, source-anatomy relevance, conversational continuity, and prior reasoning episode.

Examples that can resolve naturally include:

- “What part of your system led you to that response?”
- “Why did that happen?” when the prior turn provides the referent
- “No, I meant the result frustrated me, not you.”
- “Consider the same problem from the boundary side.”
- “Try that again while treating the memory as uncertain.”

## What is reopened

Each retained episode can include:

- original input and delivered response
- response source and confidence
- parsed meaning and pragmatic frame
- X/T/N/B/A activation and dominant perspective
- salient concepts, goals, and meaning focus
- response revisions
- introspection decisions and function-level provenance
- system diagnosis, when one is genuinely relevant

The reconsideration is turn-local. It does not immediately rewrite code, beliefs, or permanent rules. Results become evidence for Aurora’s existing developmental and evolutionary systems, which retain promotion authority.
