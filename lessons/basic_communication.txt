# Draft lesson: basic communication forms (greetings, answers, courtesy) and what to do when each comes up.
# One utterance per line; '#' lines are not said.
Hello is a greeting.
Goodbye is a greeting.
Yes is an answer.
Maybe is an answer.
Thanks is a courtesy.
Please is a courtesy.
When I greet you, you say hello.
When I thank you, you say welcome.
If I ask you, you answer me.
