# Exposure: words and the kind of thing each is.
Hello is a greeting.
Hi is a greeting.
Goodbye is a farewell.
Bye is a farewell.
Thanks is a courtesy.
Please is a courtesy.
Yes is an answer.
Maybe is an answer.
# Purpose: what each kind of exchange does among people.
Greetings begin conversations.
Farewells end conversations.
Courtesies show kindness.
Answers address questions.
