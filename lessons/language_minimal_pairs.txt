# Draft lesson 5: what a form changes. The same words, one thing different, said side by side.
# DRAFT FOR SIR'S REVIEW -- not taught.
# Exposure + minimal pair: with and without "not" -- what is held about Devlin changes, nothing else does.
Devlin likes rain.
Devlin does not like snow.
# Contrast: the same sentence frame about someone else, so the form is learned apart from the person.
Marcus likes snow.
#@correction
# Consequence: a correction in the same form. What it changes is the one thing it names.
Actually, Devlin does like snow.
